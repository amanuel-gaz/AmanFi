AFM — Amanuel Finance Manager (Black & Gold Starter)

Features in this starter: income/expense entries, ETB balance calculation, transaction history/search/type filter, local browser storage, budgets, savings goals, category reports, CSV export, theme toggle, AFM icon, PWA manifest and service worker.

Important: this is a web app starter, not a compiled native Android APK. Records are stored in browser localStorage and can be lost if browser/site data is cleared. Firebase cloud backup is not configured. Automatic bank SMS access needs a native Android implementation and permissions; it is not enabled here. AFM does not connect to bank accounts and must never ask for bank PINs, passwords or OTPs.

Preview by opening index.html. Installable/offline PWA features work best when hosted over HTTPS. To create a native APK, this source must be wrapped/ported to a native Android project and built/tested with Android tooling.
